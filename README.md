# Kingsley Isichei — Portfolio

Static portfolio site for Kingsley Uchenna Isichei — Generalist, AI Evaluation Specialist, Research & Operations Associate, Technical Writer. Content mirrors the résumé directly (same section names, same wording).

Live: https://flygerianman.github.io/Portfolio/

## Structure

```
index.html          # all page content
assets/style.css     # design system (paper/report style, faithful to résumé)
assets/script.js     # scroll-reveal + footer year
assets/Kingsley_Isichei_Resume.pdf   # downloadable résumé
```

## Editing

This is a plain static site — no build step. Edit `index.html` / `assets/style.css` directly and refresh the page locally to preview.

## Deploying updates

Any push to the `main` branch is served automatically via GitHub Pages (Settings → Pages → Source: `main` / root).
